## Using makefiles

Using these makefiles is as simple as downloading the makefile of your choice and renaming it to `Makefile`.

For example to download the [simple C project](makefiles/simple_c.mk) you can just do:

```sh
curl --output Makefile "https://raw.githubusercontent.com/Saturn7569/helpful-scripts/refs/heads/main/makefiles/simple_c.mk"
```

I also recommend reading the makefile and configuring it to your liking. The executable in the simple C project will always be named `namehere` so make sure to rename it.
